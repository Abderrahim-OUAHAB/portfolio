# Portfolio — Abderrahim OUAHAB

Portfolio personnel présentant une sélection de projets de développement web, d'intelligence artificielle et d'analyse de données.

**Site public :** https://abderrahim-ouahab.github.io/portfolio/

La page est autonome : son contenu, son style et ses interactions se trouvent dans `index.html`.

Pour la modifier, éditez `index.html` puis publiez les changements sur la branche `main`. GitHub Pages sert directement les fichiers à la racine du dépôt.
